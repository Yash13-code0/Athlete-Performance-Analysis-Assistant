# Athlete Performance Analysis Assistant

An AI-powered multi-agent system for analyzing athlete performance and generating personalized training and coaching insights.

## Technologies Used

- IBM watsonx Orchestrate
- IBM Granite
- IBM Bob
- IBM Cloud
- HTML
- CSS
- JavaScript

## Multi-Agent System

1. Athlete Data Agent
2. Performance Analysis Agent
3. Training Recommendation Agent
4. Coaching Insight Agent

## Features

- Athlete performance analysis
- Strength and weakness identification
- Personalized training recommendations
- Coaching insights
- Athlete comparison
- Progress tracking
- Interactive performance dashboard
- watsonx Orchestrate AI assistant integration
